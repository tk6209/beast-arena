# Project Memory

## Core
Beast Animation Cards – MR Beast Lab Edition. Card battle game.
Dark blue (#0d2137), neon cyan (#00e5ff), glow effects. Bangers + Nunito fonts.
Lovable Cloud backend. Supabase Realtime for multiplayer.
All game logic in PT-BR. Voice narration via Web Speech API.
DO NOT simplify combat, swarms, or evolution systems.
